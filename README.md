# 14万分の1

「80億分の1」のオマージュ。今この瞬間の土浦市の住人の誰かになり、その人が暮らす場所を見るウェブアプリ。

## 使い方

`web/index.html` をブラウザで開く（サーバー不要）。

## データの再生成

```sh
python3 scripts/build_data.py
```

`gisdata/` の行政界・250mメッシュ境界・メッシュ人口から `web/data/tsuchiura.js` を生成する。標準ライブラリのみで動く。

## 抽選の仕組み

1. 土浦市の行政界と面積を持って重なる250mメッシュを抽出する（市境をまたぐメッシュも含む）。
2. メッシュの人口（総数）に比例した確率でメッシュを選び、その範囲内で一様に1地点を選ぶ。
3. メッシュの5歳階級×男女別人口に比例した確率で階級と性別を選び、年齢は階級内で一様に選ぶ（95歳以上は95〜104歳）。

- 欠損値（`*` など）は0として扱う。
- 秘匿メッシュは年齢別人口が合算先メッシュ（`HTKSAKI`）に足し上げられているため、合算先の年齢・性別構成を使う。
